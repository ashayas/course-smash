# CourseSmash Synthetic Evaluation Suite

This directory contains the synthetic evaluation dataset and offline zero-API evaluation harness for **CourseSmash**, generated by five specialized subagents across distinct technical domains and adversarial edge cases.

## Overview

| Dimension | Value |
|---|---|
| **Total Eval Cases** | **140** |
| **Course Quality Evals (`course_quality`)** | **40** (20 good / 20 bad) |
| **Question Quality Evals (`question_quality`)** | **50** (25 good / 25 bad; 25 multiple-choice / 25 short-answer) |
| **Decision Model Grading Evals (`decision_grading`)** | **50** (24 `is_right: true` / 26 `is_right: false`; 24 `correct`, 15 `partially_correct`, 11 `incorrect`) |
| **External API Calls Used** | **0** (100% synthetic & local harness) |

## Directory Structure

- `schema.ts`: Zod validation schemas (`CourseQualityEvalSchema`, `QuestionQualityEvalSchema`, `DecisionGradingEvalSchema`, `EvalShardSchema`).
- `run_evals.mjs`: Compiler, schema validator, and zero-API local reference evaluator (`npx tsx evals/run_evals.mjs`).
- `shards/`: Individual synthetic shards produced by the 5 subagents:
  1. `shard_1_systems_cloud.json` — Systems Engineering, Cloud Infrastructure & Distributed Systems (Cloudflare Workers, D1/SQLite, MCP, Raft, QUIC, eBPF)
  2. `shard_2_bio_lifesci.json` — Computational Biology, Bio-Engineering & Life Sciences (CRISPR/Base Editing, scRNA-seq, AlphaFold, Enzyme Kinetics, PCR)
  3. `shard_3_ai_ml.json` — AI/ML, LLM Evals, Decision Models & Reinforcement Learning (KV Caching, RLHF/DPO, JEV/Clef Calibration, RAG, LoRA)
  4. `shard_4_math_algos.json` — Mathematics, Algorithms, Cryptography & Formal Logic (Spectral Decomposition, Graph Flow, ZK Proofs, Markov Chains, DP)
  5. `shard_5_adversarial_edge.json` — Adversarial, Goal-Conditioned Counterfactuals & Edge Cases (Paired identical answers graded differently based on what each user wants to learn, prompt injection in student answers, fluent traps, and circular modules)
- `dataset/`: Compiled JSONL and JSON datasets ready for evaluation pipelines:
  - `dataset/course_quality.jsonl` (40 records)
  - `dataset/question_quality.jsonl` (50 records)
  - `dataset/decision_grading.jsonl` (50 records)
  - `dataset/full_eval_set.json` (Unified dataset + metadata + baseline metrics)

## Evaluation Tasks Covered

### 1. Course Quality (`course_quality`)
Tests whether a generated multi-module course is well-designed for a user's prompt, background level, time budget, and learning goal (`what_user_wants_to_learn`).
- **Rubric dimensions (1–5)**: `alignment_with_goal`, `pedagogical_progression`, `module_coherence`, `depth_and_accuracy`, `assessment_mix` (ensuring both `multiple_choice` and `short_answer` are properly represented).
- **Failure modes covered**: `misaligned_difficulty`, `inverted_prerequisite_order`, `missing_short_answer_questions`, `off_topic_modules`, `superficial_coverage`, `hallucinated_biological_mechanism`, `mathematically_unsound`, `fluent_trap_wrong_abstraction_layer`, `circular_module_progression`.

### 2. Question Quality (`question_quality`)
Tests whether a generated `multiple_choice` or `short_answer` question is clear, unambiguous, properly keyed, and adapted to the learner's prior feedback (`prior_feedback_summary`) and learning goal.
- **Rubric dimensions (1–5)**: `clarity_and_unambiguity`, `alignment_with_user_goal`, `distractor_or_rubric_quality`, `adaptive_feedback_fit`, `difficulty_calibration`.
- **Failure modes covered**: `ambiguous_stem`, `multiple_valid_distractors`, `two_correct_options`, `wrong_answer_key`, `stem_leaks_answer`, `implausible_distractors`, `ignores_prior_feedback_state`, `ungradable_vague_prompt`, `missing_boundary_conditions_in_stem`.

### 3. JEV / Clef Decision Model Question Grading (`decision_grading`)
Tests the decision model's ability to determine whether a user's submission is right or wrong (`is_right: boolean`, `verdict: "correct" | "partially_correct" | "incorrect"`, `score: 0..1`) **conditioned on what the user wants to learn** (`what_user_wants_to_learn` and `rigor_preference: "conceptual_intuition" | "practical_applied" | "rigorous_formal"`), diagnose misconceptions, and choose the next adaptive action (`advance_to_next_module`, `ask_followup_short_answer`, `ask_remedial_multiple_choice`, `ask_harder_challenge`, `re_explain_concept`).
