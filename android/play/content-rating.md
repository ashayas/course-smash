# Content rating, audience and store settings

Answers for the forms under App content and Store settings in Play Console. They can only be filled in there. Google changes the questionnaires from time to time, so read each question; these are the facts to answer from.

## Content rating questionnaire (IARC)

| Question | Answer |
|---|---|
| Category | Reference, News, or Educational |
| Violence, blood or gore | No |
| Sexuality or nudity | No |
| Language (profanity, crude humour) | No |
| Controlled substances (drugs, alcohol, tobacco) | No |
| Gambling, simulated gambling | No |
| Can users interact or exchange content with other users? | No. A learner's courses and answers are visible only to that learner. |
| Does the app share the user's location with others? | No |
| Can users buy digital goods? | No |
| Is it a web browser or a search engine? | No |

Expected result: Everyone (PEGI 3).

## Target audience and content

| Question | Answer |
|---|---|
| Target age groups | 13 to 15, 16 to 17, 18 and over. Not designed for children. |
| Could the listing appeal to children unintentionally? | The art is a bright isometric city, so answer honestly. The app is not aimed at children, and the listing says it needs an account from a server's operator. |

## Other declarations

| Declaration | Answer |
|---|---|
| Ads | No ads |
| App access | Login required. Give reviewers a demo username and password under App access. They are never in this repository. |
| Data safety | See [data-safety.md](data-safety.md) |
| Government app, financial features, health | No |
| News app | No |
| AI-generated content | The app shows questions and feedback written by AI models. Learners report a wrong one through https://coursesmash.app/support. |

## Store settings

| Setting | Value |
|---|---|
| App category | Education |
| Tags | Education, Study guides (pick from Play's list) |
| Website | https://coursesmash.app |
| Privacy policy | https://coursesmash.app/privacy |
| Email | The owner's contact email. Play requires one, and it is shown on the listing. |
| Price | Free, no in-app purchases |
