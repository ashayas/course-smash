# Age rating answers

Answers for the age rating questions in App Store Connect (App Information, Age Rating). Only App Store Connect can set them. Apple changes the questions from time to time, so read each one; these are the facts to answer from.

| Question | Answer |
|---|---|
| Violence (cartoon, realistic, prolonged), sexual content or nudity, profanity or crude humour, alcohol, tobacco or drug use, mature or suggestive themes, horror or fear themes, medical or treatment information | None |
| Gambling, simulated gambling, contests, loot boxes | No |
| Unrestricted web access | No. The app opens three kinds of link in the phone's browser, not inside the app: the privacy page, the support page, and a source link under some answers. |
| User-generated content, messaging or chat between users | No. A learner's courses and answers are visible only to that learner. |
| Advertising | No |
| Parental controls, age assurance | No |
| Content written by AI | Yes, if asked. Questions and feedback are written by AI models from the course's subject. Learners cannot prompt the models freely, and can report a wrong question through the support page. |

Expected result: the lowest rating, 4+. The app is not in the Kids category, and the policy at https://coursesmash.app/privacy says it is not aimed at children under 13.

Pricing and availability are also set only in App Store Connect: the app is free, with no in-app purchases.
